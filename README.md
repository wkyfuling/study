# study

小学生数学测试系统（Java 控制台 & GUI 版）

## 功能简介
- 选择难度（简单/中等/困难）决定题目数字范围。
- 自定义题目数量（5-30 道）。
- 随机生成加、减、乘、除混合运算，自动避免除法出现余数。
- 逐题即时反馈，结束后显示总成绩。
- 提供图形界面：按钮启动测试、输入框作答、提示区显示反馈。

## 运行方法
1. 确保本机已安装 JDK 8+，并在终端进入仓库根目录。
2. 编译源代码：

   ```bash
   javac -d out $(find src -name "*.java")
   ```

3. 运行 GUI 版（推荐给学生使用）：

   ```bash
   java -cp out com.example.mathquiz.MathQuizGUI
   ```

   - 选择难度和题目数量后点击 **开始测试**。
   - 在答题区输入答案并点击 **提交答案**，底部即时显示对错和正确答案。
   - 答完全部题目后会弹出得分提示。

4. 如需控制台版，可运行：

   ```bash
   java -cp out com.example.mathquiz.MathQuizApp
   ```
