# Youth League Office System

This is a simple example of a "智慧团学办公系统" (Youth League Office System) written in Java. The project uses Maven for building.

## Building and Running

```bash
mvn package
java -cp target/youth-league-office-1.0-SNAPSHOT.jar com.example.youthleague.YouthLeagueOfficeSystem
```

The application is console based and allows you to add/list members and events.
