# study

小学生数学测试系统（Java 控制台版）

## 功能简介
- 选择难度（简单/中等/困难）决定题目数字范围。
- 自定义题目数量（5-30 道）。
- 随机生成加、减、乘、除混合运算，自动避免除法出现余数。
- 逐题即时反馈，结束后显示总成绩。

## 运行方法
1. 确保本机已安装 JDK 8+，并在终端进入仓库根目录。
2. 编译源代码：

   ```bash
   javac -d out $(find src -name "*.java")
   ```

3. 运行程序：

   ```bash
   java -cp out com.example.mathquiz.MathQuizApp
   ```

4. 根据提示完成测试：
   - 选择难度：输入 1（简单）、2（中等）或 3（困难）。
   - 设置题目数量：输入 5-30 之间的整数。
   - 逐题作答：直接输入答案并按回车，题目即时判分。
